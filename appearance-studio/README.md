# استوديو تخصيص المظهر — نسخة للمراجعة

فرع التطوير: `feature/appearance-studio-community-dashboard`.
الأساس: `e637dccaa487c3a2565255a9125c35c0d57ca7bb`.
لا يُدمج هذا الفرع ولا يُنشر على GitHub Pages قبل اعتماد المستخدم.

## ما تم تنفيذه

- لوحة جانبية RTL تفتح من أيقونة لوحة الألوان بجوار أداة تعديل المحتوى، دون إعادة تحميل الصفحة أو تغيير التبويب.
- أربعة أنماط: الأصلي، الأخضر المؤسسي، الأزرق التنفيذي، العنابي المؤسسي؛ باستخدام الأخضر `#3A564C` والعنابي `#6C2947` والذهبي `#CCA862`.
- تخصيص مستقل لكل نمط، مع تمييز «نسخة مخصصة» وفصل القيم الأساسية عن تفضيلات المستخدم.
- الخط الأصلي وIBM Plex Sans Arabic وNoto Sans Arabic؛ ملفات ويب محلية وتراخيص OFL. لم يُضف DIN لعدم توفر ترخيص ويب موثق.
- النصوص من 90% إلى 130%، والأرقام من 85% إلى 130%، وأربعة أحجام جاهزة. ضبط الأرقام الطويلة داخل المساحة المتاحة بعد تحميل الخط وحركة العدّ.
- ثمانية ألوان مع منتقي وHEX. حفظ التفضيلات معطّل عند ضعف التباين أو عدم صحة HEX. الألوان العكسية على المساحات الداكنة والشعارات ودلالات الحالات محفوظة.
- ثلاثة أشكال للبطاقات، مع الاستدارة والظلال والحدود والحشو ضمن نطاقات محددة.
- حركة هادئة/قياسية/حيوية/إيقاف غير الضروري، مع أولوية إعداد الجهاز لتقليل الحركة. يشمل حركة العدّ في النظام الرئيسي.
- حفظ محلي بإصدار ومفتاح مستقل `busola.appearance.v1`؛ لا يتضمن بيانات تشغيلية أو رموز دخول. لا يكتب إلى GitHub.
- استعادة أساس النمط أو التصميم الأصلي الكامل. المسودات لا تُحفظ تلقائياً.
- دعم جذر التواصل والإعلام المنفصل وواجهات HTML التابعة، وتزامن المظهر مع الإطارات من المصدر نفسه.

## لوحة خطة التواصل المجتمعي

`overrides/reports/community-communication-plan-2026.html` يعرض جميع صفوف الإكسل الـ83 وحقولها الـ13، مع البحث، والتصفية حسب المسؤول والنوع والربع، والبطاقات، وتوسيع التفاصيل، والجدول الكامل، والطباعة.

تظهر الخطة في موضعيها الحاليين: الحوكمة والمبادرات ← خطة التواصل المجتمعي، والتواصل والإعلام ← التواصل المجتمعي. تغير رابط الاستعراض إلى HTML؛ بقي الإكسل متاحاً كمصدر أصلي داخل اللوحة.

عدد الصفوف لا يساوي عدد مرات التنفيذ: 79 هو مجموع خانة العدد في البنود الأربعة المجمعة. توزيع الصفوف على الأرباع: 25، 17، 16، 22؛ وثلاثة صفوف بلا ربع. لم تُحذف التكرارات ولم تُصحح تواريخ المصدر افتراضياً.

## البنية والتشغيل

- `themes.css`: القيم الأساسية للأنماط.
- `themes.js`: مواءمة ألوان CSS الحالية مع الرموز الدلالية، بما فيها Shadow DOM، مع استعادة القيم الأصلية.
- `appearance-studio.js/.css`: الواجهة والتفضيلات والتطبيق المباشر.
- `contrast.js`: حساب التباين والخلفيات الشفافة والمتدرجة.
- `integrate.py <built-platform-directory>`: نسخ الأصول وربط الصفحات بعد بناء المنصة؛ يحتفظ بملفات UX الحالية في نهاية ترتيب التحميل.
- `build-plan.py`: إعادة توليد لوحة الخطة من الإكسل باستخدام openpyxl.
- `verify.py`: التحقق من جميع خلايا البيانات والأعداد وسلامة JavaScript وثبات ملفات البيانات والتحرير والحماية.
- `review.html`: مختبر مراجعة مستقل بإطار ذي عروض 390/768/1440/1920. لا يضاف إلى الموقع الرسمي بواسطة أداة الدمج.
- `isolation.js`: قيد خاص بالمعاينة المستقلة يمنع الكتابة الخارجية. لا تحقنه أداة الدمج في الموقع الرسمي.

التحقق:

```sh
python appearance-studio/verify.py
node scripts/test_catalog_overrides.mjs
node --check overrides/assets/motion-system.js
```

## حدود التحقق

المراجعة في Chromium وبمقاسات عرض تحاكي الهاتف واللوحي والكمبيوتر والشاشة الكبيرة؛ ليست شهادة توافق فعلية مع Safari وFirefox أو أجهزة iOS/Android. الصفحات المكوّنة من صور أو PDF لا يمكن تغيير الخط المرسوم داخلها. المحتوى المحمي لم يُفتح أو يُفك تشفيره؛ فُحصت واجهة الدخول فقط، ويلزم اختبار محتواه الداخلي بحساب مخول قبل اعتماد النشر. كذلك لم يُجرّب الحفظ التشغيلي الخارجي من المعاينة المعزولة.

لا تتغير ملفات البيانات التشغيلية أو آلية التحرير أو التشفير في هذا الفرع. التغيير في `motion-system.js` يخص تفضيلات الحركة المرئية فقط.
