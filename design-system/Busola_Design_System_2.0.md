# Busola Design System 2.0

مرجع التصميم البصري لمنصة «بوصلة المتعامل» — المديرية العامة لخدمات المتعاملين، صندوق الحماية الاجتماعية.

حالة الإصدار: نسخة تطوير للمراجعة، وليست موافقة نشر. الفرع: `design/busola-system-2-review`. أساس العمل: `a0d11121b34a3018f03e92533fb7e8086935f9b3`. يعرض هذا المرجع القواعد المنفذة؛ نتائج الفحص الفعلي وقيوده تُوثَّق في تقرير الجودة المستقل.

## نطاق النظام

تُطبق القواعد الجديدة على الأخضر المؤسسي والأزرق التنفيذي والعنابي المؤسسي. التصميم الأصلي مستثنى من `data-bs-active` ومن التوزيع الداكن الجديد. لا تتغير النصوص أو الأرقام أو ترتيب التنقل أو مصادر البيانات أو التشفير أو صلاحيات التحرير والحفظ.

يمثل 60–30–10 توازناً بصرياً: خلفية داكنة مسيطرة، وأسـطح ونصوص مساندة، وذهبي محدود للأولوية. توزيع البطاقات الداكنة والفاتحة يستهدف قرابة 70/30 بحسب وظيفة المحتوى. ليس ذلك نسبة مضمونة لعدد كل عناصر DOM؛ كثرة الشهادات أو كثافة الجداول قد تغير العدد دون أن تعكس مساحة الصفحة أو سهولة قراءتها.

## الخطوط والمقاسات

الخط الأساسي للأنماط الجديدة `StudioNoto`، وهو الاسم المحلي لملفات Noto Sans Arabic؛ يليه Noto Sans Arabic ثم `StudioPlex` وIBM Plex Sans Arabic. لا يتضمن الإصدار خط DIN Next LT Arabic لعدم توفر ترخيص ويب موثق. ملفات الخطوط المحلية الموجودة هي المرجع عند التشغيل دون اتصال خارجي.

| الرمز | القيمة الفعلية |
|---|---|
| `--bs-type-page` | `clamp(28px, 2.5vw, 36px)` |
| `--bs-type-section` | `clamp(24px, 2vw, 28px)` |
| `--bs-type-card` | `clamp(17px, 1.35vw, 18px)` |
| `--bs-type-body` | `16px` |
| `--bs-type-support` | `14px` |
| `--bs-type-hero` | `clamp(48px, 6vw, 88px)` |
| `--bs-type-kpi` | `clamp(36px, 4.2vw, 60px)` |
| `--bs-type-secondary` | `clamp(26px, 2.5vw, 34px)` |
| `--bs-type-table` | `clamp(16px, 1.25vw, 18px)` |

عند عرض لا يزيد على 520px تصبح مستويات الأرقام الثلاثة 48 و36 و28px. عند عرض 1800px فأكثر مع وضع الشاشة الكاملة أو علامة العرض التنفيذي، تصبح 112 و72 و44px، وأرقام الجداول 24px. العنوان في شريط التطبيق أصغر من عنوان الصفحة حتى لا يستهلك مساحة العرض.

العناوين والأرقام بوزن 700. تباعد الأسطر 1.85 للنصوص، و1.7 للمساند، و1.5–1.65 للعناوين، و1.25 للأرقام. يُستخدم `tabular-nums`، وتُكيَّف الأرقام الطويلة داخل بطاقتها منفردة بواسطة `--bs-fit`، بدلاً من تصغير جميع البطاقات.

## المكونات والأسطح

يحدد `data-bs-component` عائلة المكوّن، ويحدد `data-bs-surface` سياق القراءة. يحدد `data-bs-kpi` مستوى الرقم. تُضاف هذه العلامات إلى المكونات الحالية دون إعادة إنشاء المحتوى أو نقل معالجات الأحداث.

| العائلة | الغرض | السطح الافتراضي |
|---|---|---|
| `executive` | الهيرو والملخص التنفيذي | داكن |
| `performance` | المؤشرات وبطاقات الأداء | داكن |
| `geographic` | التغطية والإحصاءات الجغرافية | داكن |
| `information` | المعلومات والملخصات القصيرة | داكن |
| `achievement` | الإنجازات والتكريمات | داكن |
| `project` | حالة المشاريع | داكن؛ التفاصيل النصية الطويلة لها أولوية الفاتح |
| `timeline` | الخطوات والتسلسل الزمني | داكن افتراضياً |
| `comparison` | المقارنات والرسوم التفصيلية | فاتح |
| `detail` | الشرح الطويل والجداول والتحرير | فاتح |

تُطبق الأسطح بحسب أسماء المكونات ووظيفتها، وليس باستخدام `nth-child` لتلوين البطاقة الثانية أو الثالثة. توجد مواءمة احتياطية للأسطح الموروثة؛ ويُضاف أي مكوّن جديد إلى خريطة العائلات أولاً. تُستثنى الشعارات الرسمية والأيقونات ذات العلامة التجارية من التصنيف العام.

الحشو الافتراضي للمكوّن 24px، وينخفض إلى 16px على الشاشات الأصغر. الحدود 1px؛ ويُستخدم 3px في مواضع إبراز محددة. لا يُفرض ارتفاع عام ثابت على جميع البطاقات. تُوسَّط أيقونات المكونات المعروفة داخل حاوياتها، ويكون SVG القياسي داخلها 24px؛ وتبقى مقاسات العلامات التجارية مستقلة.

## الحركة والتفاعل

| الرمز | القيمة |
|---|---|
| `--bs-motion-press` | `180ms` |
| `--bs-motion-menu` | `250ms` |
| `--bs-motion-reveal` | `420ms` |
| `--bs-motion-data` | `1100ms` |
| `--bs-ease` | `cubic-bezier(.2,.7,.2,1)` |

يُستخدم زمن الضغط في تفاعلات عناصر التحكم، وتستخدم الأرقام 1100ms في الأنماط الجديدة مع مراعاة اختيار الحركة في الاستوديو. رمزا القوائم والظهور مرجع للمكونات المتوافقة؛ لا تعني إضافتهما استبدال كل حركة موروثة آلياً. إعداد النظام `prefers-reduced-motion` له الأولوية. خيار إيقاف الحركة غير الضرورية يوقف الانتقالات والحركة المرئية ذات الصلة.

## التخصيص والتوافق مع الأصل

يظل الاستوديو الحالي هو واجهة التخصيص الوحيدة. تُحفظ التفضيلات في `busola.appearance.v1` لكل نمط على حدة، وتُطبق كقيم شخصية فوق الرموز الأساسية؛ لا تعدّل ملفات النظام أو بيانات التشغيل.

تشمل الرموز الشخصية الحجم والخط والأرقام والبطاقة والحشو والاستدارة والظل والحدود والعناوين. يمنع فحص التباين حفظ ألوان غير مقروءة وفق قواعد الاستوديو. يجب التحقق من الحفظ والاستعادة والتنقل بين الأصل والأنماط في تقرير الاختبارات؛ لا تكفي قراءة المصدر لإثباتها.

## ترتيب CSS وقابلية الصيانة

تعتمد قواعد المواءمة على طبقة واحدة مسماة `@layer busola`. تحتوي المنصة الأصلية عدداً كبيراً من قواعد `!important` غير المجمعة في طبقات. لذلك تستخدم الطبقة الجديدة `!important` بشكل محصور لامتلاك الخصائص المرئية في الأنماط الجديدة؛ فالقاعدة المهمة داخل الطبقة تسبق القاعدة المهمة الموروثة خارج الطبقات.

هذا حل توافق يحافظ على الأصل، وليس إزالة شاملة لجميع CSS الموروث. يجب تعديل الرمز أو قاعدة المكوّن المركزية بدلاً من إضافة ملفات تجاوز متفرقة. تبقى أصول التنقل وUX في ترتيب التحميل الذي تعتمد عليه فحوص البناء الحالية.

## الوصول والرسوم

يستهدف النص العادي تباين 4.5:1، والنص الكبير والعناصر الرسومية ذات المعنى 3:1 حيث ينطبق WCAG AA. تظهر حلقة تركيز واضحة، وتبقى التسميات والأرقام بجانب دلالات الحالة. تستعمل الجداول أسطحاً فاتحة؛ ويُراعى النص العكسي في الأسطح الداكنة.

تتكون رسوم المنصة الحالية غالباً من أشرطة وحلقات CSS وSVG. لا يُستبدل مقدار النسبة أو عرض شريط البيانات أو مصدره عند تغيير اللون. تُخصص الألوان المساندة للمقارنات، ويبقى الذهبي للأولوية. النص المرسوم داخل صورة أو PDF لا يمكن تغييره بتنسيق CSS.

## حدود هذه الوثيقة

هذه الوثيقة مرجع تنفيذ، وليست شهادة نجاح للمراجعة البصرية أو التوافق. تفاصيل التغطية في `coverage.md`، والأدلة ونتائج الفحص في تقرير الجودة. لا نشر أو دمج في `main` قبل الموافقة الصريحة.
