# نسخة مراجعة Busola Design System 2.0

التطوير محصور في `design/busola-system-2-review`. لا تُدمج هذه النسخة في `main` ولا تُشغَّل عملية نشر Pages قبل موافقة صاحب المشروع.

## تشغيل الحزمة

فك ضغط `Busola_2_Review.zip`، ثم شغّل `start_preview.py` باستخدام Python 3. يفتح المتصفح نسخة محلية على `http://127.0.0.1:8765/`. يمكن أيضاً تشغيل `python -m http.server 8765` من مجلد الحزمة وفتح الرابط نفسه.

المعاينة تحتوي على المنصة وجميع تبويباتها، الأنماط الأربعة، العرض القيادي، ملتقى المحافظات، وخطة التواصل المجتمعي والتقارير التابعة. استخدم قائمة النمط أو استوديو المظهر الموجود. يعرض محدد المقاسات العرض الفعلي داخل إطار متناسب مع شاشتك.

فتح HTML مباشرة عبر `file://` لا يكفي، لأن المنصة تحمل بيانات وأجزاء واجهتها محلياً عبر HTTP. بعض شعارات الجهات والروابط الخارجية تحتاج إلى الإنترنت. صفحات المحتوى المحمي تحتفظ بكلمة مرورها.

في الحزمة فقط، يمنع `preview-isolation.js` طلبات الكتابة الخارجية، ويعطّل إدخال رمز GitHub. التفضيلات الشخصية تعمل محلياً. لا يُضاف هذا الحاجز إلى موقع الإنتاج.

## ملفات المرجع

- `Busola_Design_System_2.0.md`: الألوان، الخطوط، المقاسات، العائلات، الحركة، التباين والتكامل.
- `coverage.md`: جرد التبويبات والصفحات والتغطية وحدودها.
- `QA_Report.md`: الاختبارات المنفذة والنتائج والقيود المتبقية.
- `qa/`: تقارير فحص قابلة للقراءة الآلية والتحقق من سلامة الملفات.
- `review.html`: واجهة مراجعة تستخدم مجلدي `before/` و`after/` عند إعداد المقارنة التطويرية. حزمة التسليم تتضمن النسخة المطورة وصور المقارنة.

الملفات الأصلية للمحتوى والبيانات والتشفير لم تُستبدل. إعادة بناء الموقع للإصدار النهائي تتم عبر خط البناء الحالي بعد المراجعة والاعتماد؛ إعدادات النشر لم تتغير.
