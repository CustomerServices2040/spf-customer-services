# بوصلة المتعامل — مراجعة التطوير البصري الشامل

نسخة تجريبية للمراجعة بتاريخ 10 نوفمبر 2026. الفرع: `design/full-visual-transformation-2026-11-10`.

تشمل المعالجة البصرية الأقسام الرئيسية الـ21، وصفحات التواصل والإعلام الست، وتبويبات ملتقى دوائر المحافظات الست، وواجهتي المشاركة والميسّر، واللوحة التفصيلية للأعمال، وتقرير الداخلية. النسخة جاهزة للمراجعة البصرية، **وليست اعتماداً نهائياً لاختبار جميع الوظائف**: المحتويات المشفرة والحفظ الخارجي والجلسات الحية لم تُختبر كاملاً.

## الدخول والمقارنة

- [المعاينة الخاصة](https://busola-visual-pilot-20261110.spf2040.chatgpt.site/review): اختيار القسم، التصميم الأصلي/المطور، وستة مقاسات عرض، ثم جدول التغطية وصور المقارنة.
- [ملخص نتائج المتصفح](browser-checks.json) و[فحص سلامة المحتوى والأصول](integrity.json).
- الصور الأربع عشرة في هذا المجلد تعرض سبع مقارنات فعلية بالمقاس نفسه: نظرة عامة، الأداء، المحافظات، المشاريع، التواصل والإعلام، الملتقى، ولوحة الأعمال. موضع التمرير قد يختلف قليلاً بسبب اختلاف ارتفاع المحتوى.
- الوصول إلى المعاينة خاص بصاحب الحساب. بعض الروابط الخارجية الأصلية تبقى متجهة إلى وجهاتها الأصلية؛ استخدم محدد الأقسام في صفحة المراجعة للتجارب المحلية المرتبطة.

## ما تغير

1. نظام بصري مؤسسي بالأخضر والذهبي والعنابي، مع أسطح عاجية، وتكوين افتتاحي مستلهم من القوس العماني. اختلاف المعالجة بين مؤشرات الإدارة والبيانات الجغرافية والمشاريع والإنجازات، دون نقل المحتوى بين أقسامه.
2. خط عربي محلي التحميل، مستويات أوضح للعناوين والأرقام والمصادر، أرقام متناسقة، تباين أفضل، ومساحات تراعي كثافة كل نوع من المحتوى.
3. شريط تنقل متسق مع البنية الأصلية، حالات تركيز واضحة، وتنسيق الحوارات والحقول والجداول والأزرار والشاشة الكاملة. شملت المعالجة مكوّن التواصل والإعلام داخل Shadow DOM والصفحات المستقلة داخل المشروع.
4. تطوير خريطة المحافظات ولوحاتها وبطاقات القنوات والمركز الذكي، مع المحافظة على الشعارات والبيانات الأصلية. الأدوات التفصيلية تظل متاحة بالضغط، ولا تُخفى القيم الأساسية داخل التلميحات.
5. استمرار محرك الأرقام والمخططات الأصلي، مع ظهور هادئ للعناوين وتفاعل متسق واحترام تقليل الحركة. عولجت حلقات الحركة القديمة في **مخرجات تقرير الداخلية فقط** بتحويل محدد قابل للعكس والتحقق، دون استبدال البيانات أو المكتبات.

لم تُضف GSAP أو ECharts أو Lottie أو إطار عمل جديد؛ لم تكن إضافتها لازمة لتنفيذ هذا النطاق. لم يُنشأ مؤشر أو رسم ببيانات مفترضة.

## التدقيق الذي وجّه التنفيذ

وجد التدقيق طبقات CSS متعاقبة ذات قواعد `!important` وتخصيصات مختلفة للأقسام، وصفحات مستقلة لا ترث تنسيق المنصة، وShadow DOM للتواصل والإعلام. النسخة السابقة كانت محدودة النطاق وتعتمد على معالجة متجانسة للبطاقات، ولم تعالج اختلاف البيئات أو كثافة المحتوى بالقدر الكافي. النسخة الحالية تضيف ملفات عرض محددة النطاق بدلاً من تعديل مصادر البيانات أو إعادة ترتيب DOM المرتبط بمفاتيح التحرير.

راجعت الهوية والمواد التي أمكن الوصول إليها والمراجع المؤسسية والتصميمية؛ تعذر فتح منشورات إنستغرام ودليل الهوية العام وبعض محتوى Figma Community. لا يُدّعى الاطلاع عليها. التفاصيل والروابط في [تدقيق المرجعيات](reference-audit.md).

## حدود مهمة قبل الاعتماد

- لم يُنفذ حفظ أو نشر إلى GitHub من المنصة. دوال الحفظ الأصلية تستهدف `main`؛ المعاينة تحتوي حارساً مستقلاً يمنع الكتابات الخارجية. لا تدخل رموز الوصول في المعاينة.
- لم تُفتح التبويبات الثلاثة المحمية، ولا يمكن وصف مكوناتها الداخلية بأنها اجتازت المراجعة البصرية الفعلية. لا تغيير للصلاحيات أو التشفير.
- جلسات الملتقى وإرسال الإجابات تتطلب خدمة الغرف الحية غير الموجودة في المضيف الثابت الخاص؛ لم تُنشأ جلسة ولم تُرسل إجابة.
- لم تُختبر جميع احتمالات الاستيراد والتحرير والسحب والإفلات وكل زر داخل معارض التقرير. الاختبارات الآلية القائمة لا تعادل تحققاً شاملاً لكل مسار عمل.
- لم يُنفذ اختبار Safari أو iOS/Android فعلي أو تدقيق وصول شامل باستخدام قارئ شاشة. بعض الشعارات الخارجية الموروثة تعتمد على توفر مضيفها.

## الملفات وطريقة البناء

التغييرات الجديدة محصورة في `preview-v2/` و`docs/visual-transformation/`. لا تعديل لملفات المنصة الأصلية أو إعداد GitHub Pages. يعتمد هذا الفرع على ملفات المعاينة السابقة الموجودة في فرع التجربة، ولا يدمجها في `main`.

```bash
python preview-v2/build_review.py
python preview-v2/prepare.py
python preview-v2/check_integrity.py
```

شغّل `dist` بخادم HTTP محلي من جذره. المسارات المطلقة للمعاينة تفترض الجذر؛ لا تفتح `index.html` مباشرة بنظام `file://`. النسخة المبنية مستقلة عن النشر الرسمي، وتبقى عملية تعميمها على الإنتاج خطوة منفصلة بعد المراجعة والموافقة الصريحة.
