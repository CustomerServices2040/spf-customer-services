# الأقسام المرتبطة بالمنصة — جرد التطوير البصري

هذا الملف يوثق نطاق ملف `preview-v2/linked.css`. لا يغيّر الملف نصًا أو قيمة أو ترتيب تبويب أو مصدر بيانات أو آلية حفظ. يُحمّل بعد الأنماط الأصلية في النسخة التجريبية فقط.

## طريقة الدمج

| الصفحة الأصلية | قيمة `data-vt-page` على عنصر `html` | المعالجة |

| `overrides/forum/index.html` | `forum` | الملتقى بجميع تبويباته الستة والتفاصيل الديناميكية |
| `overrides/forum/join.html` | `forum-join` | نموذج المشاركة وحالاته الحالية |
| `overrides/forum/facilitator.html` | `forum-facilitator` | شاشة الميسّر والجلسة والمؤقت والمشاركات |
| `overrides/assets/work-tracker.html` | `work-tracker` | لوحة الموقف التنفيذي وتبويباتها الأربعة |
| `overrides/reports/dakhiliyah-june-2026.html` | `dakhiliyah` | صفحات التقرير والمؤشرات والأزرار |
| `overrides/communications/index.html` | لا يحتاج قيمة مستقلة | الصفحة تحويل مباشر إلى `../index.html#communications`؛ التطوير يتم داخل المنصة الرئيسية |

تستخدم الأنماط `--vt-font` للخط المشترك، مع بدائل PlexArabic وIBM Plex Sans Arabic. يجب تحميل الخط المحلي في الصفحات التي لا تحمل أصلًا ملف `vivid.css`.

## الاستجابة والحركة

الأنماط تتضمن نقاط استجابة عند 1200 و900 و620 بكسل وتحسينات للشاشات الأكبر من 1700 بكسل. لا يُعد ذلك وحده إثباتًا لفحص الأجهزة؛ يلزم اختبار المتصفح النهائي على القياسات المطلوبة.

الظهور الجديد 650ms، تفاعلات الإدخال 220ms، درج المهام 340ms. تستجيب الحركات التي يضيفها CSS لتفضيل تقليل الحركة. **التقرير يتضمن حلقات JavaScript أصلية متواصلة لتحريك المعارض؛ تعطيل CSS وحده لا يوقف تلك الحلقات.** يجب الإفصاح عن هذا القيد أو معالجته في طبقة الحركة دون تغيير المحتوى أو التفاعل.

## حدود ومخاطر تحقق محددة

- `forum/config.js` يتصل بخدمة الملتقى القائمة. بدء جلسة أو إرسال إجابة يعد كتابة خارجية؛ لم يُنفذ أثناء هذا العمل. يجب أن تبقى المعاينة معزولة عن كتابات الموقع الرسمي.
- صفحة الملتقى تحتوي رابطًا ثابتًا للمنصة الرسمية، و`forum.js` يحتوي رابط تقرير الداخلية الرسمي. ينبغي لمضيف المعاينة توفير مسارات مراجعة داخلية منفصلة؛ لا يجب تغيير مصادر البيانات الأصلية.
- واجهات الميسّر والمشاركة تستخدم صورة شعار من مضيف الملتقى الخارجي. لم تُستبدل علامة تجارية. يُفضّل توفير نسخة محلية من الأصل نفسه في تجميع المعاينة إذا تعذر تحميله.
- لوحة المهام تستخدم Chart.js وSheetJS وOAuth والكتابة في GitHub على `main`. هذه وظائف قائمة لا يعيد ملف الأنماط تعريفها. لا يُنفذ اعتماد أو نشر أثناء اختبار النسخة التجريبية.
- لوحة المهام مستقلة ويستدعيها القسم المحمي في المنصة. أنماط صفحة الأب لا تعبر iframe، لذا يجب تحميل `linked.css` داخل نسخة iframe نفسها.
- التقرير ملف HTML كبير (3.37MB) مع صور وخلفيات مضمنة وعدد كبير من التصحيحات المتعاقبة. أبقيت الصور والهندسة الحالية؛ أوامر CSS المشروطة لا تقلل حجم أصوله ولا تعيد بناءه.
- لم أغيّر أيّ ملف أصل داخل `overrides/`، ولم أعدّل بيانات، أو أمن، أو أدوات جلسة أو نشر.
